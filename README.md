### 🤖 Agentic AI & AIGC

I'm particularly interested in moving large language models beyond one-shot generation and into systems that can understand context, use tools, retrieve knowledge, and complete meaningful tasks.

- Exploring **agent harness engineering**: the runtime layer that connects models with tools, environments, memory, permissions, observability, and verification
- Designing agent workflows with clear responsibilities, state, and execution boundaries
- Connecting models to APIs, tools, data sources, and external services
- Exploring retrieval-augmented generation (RAG), memory, and context-engineering strategies
- Building human-in-the-loop flows for review, correction, and controlled execution
- Evaluating generated content for relevance, factuality, consistency, and usefulness
- Applying text and multimodal generation to practical product and engineering scenarios
- Improving agent reliability through observability, structured outputs, retries, and guardrails

### 🧪 Frontier agent technologies

I'm following and experimenting with the rapidly evolving infrastructure around general-purpose and coding agents:

- **Agent harnesses** — model-independent runtimes for context selection, tool access, task state, sandboxing, permissions, verification, and trace-based evaluation
- **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** — an open agent ecosystem focused on persistent context, skills, tool use, and continuous improvement
- **Model Context Protocol (MCP)** — standardized connections between agents and external tools, applications, and data sources
- **Agent-to-Agent (A2A) communication** — interoperable task delegation and collaboration between specialized agents
- **Agent Skills** — reusable packages of instructions, resources, and scripts for reliable domain-specific workflows
- **Self-evolving agents** — improving prompts, skills, memory, and execution strategies through feedback and evaluation
- **Durable agent execution** — resumable workflows, checkpoints, retries, event-driven tasks, and long-running state
- **Coding agents** — repository understanding, planning, implementation, testing, review, and evidence-backed completion

### 🎬 Generative video

I'm exploring how modern generative models can support the complete video-creation lifecycle, from early concepts and storyboards to controllable generation, editing, and delivery.

- **Text-to-video and image-to-video** — translating prompts, reference images, and visual concepts into coherent motion
- **Controllable generation** — guiding composition, camera movement, subject motion, timing, and visual style
- **Temporal consistency** — preserving identity, objects, environments, and visual quality across frames and shots
- **Character and scene continuity** — maintaining narrative and visual consistency across multi-shot sequences
- **Multimodal storytelling** — coordinating scripts, images, video, speech, music, and sound effects
- **Video agents and workflows** — orchestrating research, scripting, storyboarding, asset generation, editing, and quality review
- **Efficient generation** — exploring inference speed, cost, resolution, duration, and quality trade-offs
- **Quality evaluation** — assessing prompt alignment, motion quality, visual fidelity, continuity, safety, and audience usefulness
